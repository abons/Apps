# ai-sessie: gameplay van de drie woordspellen (2026-10-24)
Per app (`wordguesser`, `wordpuzzle`, `wordfinder`):
- `NOTES.md` - begin hier: commit, wat de beelden tonen, UX-punten, animaties.
- `0N-*.jpg` - 4 verkleinde sleutelbeelden (450x1000, ~40 KB).
- `anim-0N-*.jpg` - filmstrips van animaties: 8 frames in een 4x2 raster (~1100x1200), links→rechts, boven→onder, op echte frametijden uit de opname.
- `gameplay.mp4` - voor mensen; ~900 frames, niet voor een AI lezen.
Open hooguit de beelden die je nodig hebt. De mp4's zijn opgenomen op de Motorola via USB (debug-builds).
